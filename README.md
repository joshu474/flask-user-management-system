Flask User Management system

overview

This is a Flask web application that provides a secure user management system.

The application allows users to register, log in, edit their profile, change their password, and log out securely. Passwords are stored using secure hashing instead of plain text.

Features
- User registration
- Secure login
- Password hashing
- Edit profile
- Change passwords
- Protected routes
- User dashboard
- Git version control
- GitHub repository

Technologies Used
* Python
* Flask
* HTML
* CSS
* SQLite
* Git
* GitHub
